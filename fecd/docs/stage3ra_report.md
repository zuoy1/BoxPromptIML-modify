## 1. 结论与停止决定

**行动判断：STOP；不申请开放 new_confirm GT。** 唯一候选 q_A 未满足预先冻结的 high_pos 主效应门槛，也未满足同 coverage 正类风险门槛。自动统计标签为 INSUFFICIENT EVIDENCE，表示开发证据不足；依据用户的提前停止规则，本轮行动为停止新增排序方法，而非继续在 new_dev 搜索公式。没有 DEVELOPMENT PASS、GO-to-confirm 或独立确认结论。

## 3. A1：预冻结分数、候选集合与统计口径

协议在首次开发 GT 读取前写入 stage3ra_protocol.json，hash 为 da321d59885e225d49c8b310ab663b333f78194b040c15e3be962c4c162b24dc。没有增加额外公式、权重、可训练网络或按结果改阈值。

六个可靠性分数（高分表示可靠）：
1. base_margin = 2 abs(base_mu−0.5)。
2. mean_margin = 2 abs(mu−0.5)。
3. variance = 1−clamp(4 var, 0, 1)。
4. threshold = 1−4 agreement(1−agreement)。
5. c_sam = variance × threshold × sqrt(2 abs(mu−0.5))。
6. q_A = c_sam / (1+abs(mu−base_mu))。

所有方法均以 K8 mu≥0.5 定义相同预测正负候选；base_margin 未换成 K1 预测集合。实际逐张检查 K8 base_mu 与冻结 K1 mu 一致。high_pos 为 K8 正类且 c_sam≥0.90、var≤0.01；high_neg 对应负类。所有分数有限且在 [0,1]，单元测试检查公式、方向、边界和单调性。

GT 入口只允许精确匹配冻结 new_dev allowlist 的记录；在读取文件前核对角色及身份，拒绝其他角色及伪造键。读取 prepared GT 字节记录哈希，检查二值 0/255、native 尺寸，nearest-neighbor 到 224×224，>127 二值化。数组级评分及统计模块不读取 mask。访问日志是受控入口的应用级记录，不是操作系统级全局文件访问证明。

Box union 向内腐蚀 3 像素为 inside，原 union 余下为 edge，外扩 5 像素减 union 为 ring，其余 far；每个分层比较均固定同一候选集合及 coverage，避免仅比较区域组成不同的子集。

主要指标为 high_pos AUROC 差；次指标为 pos risk@50%；负类守门为 neg risk@50%。预定门槛分别为差≥0.02 且 CI 下界>0、差≤−0.002 且 CI 上界<0、负类风险 CI 上界≤0.001。域支持要求至少 20 有效组、20 配对图像和 50 错误像素，本轮仅 CASIA 达到组数量要求。

主要结果是逐图精确计算后等图像加权宏平均，不能把像素作为独立样本。配对 bootstrap 2000 次、seed=20261029，以整个来源代理组抽样；同时报告组等权敏感性。AUROC 单一标签为 N/A；AUPRC 无错误为 N/A、全错误为 1；候选为空或固定 coverage 保留不足 10 像素的指标保留 N/A 及原因。不同指标有效图像数可能不同。AUPRC 使用 1−可靠性检测错误，与 prevalence 同时报告。

风险主分析在相同 coverage 下对边界 ties 做同分组内标签无关的等比例期望分配；另报告固定随机种子的整数选择。AURC 用完整逐图精确排序计算；图中五档点连线只是可视化辅助。pooled micro 使用预冻结 4096 桶统一可靠性直方图，是描述性近似，不作为主要效应检验。

为检查 margin/variance 解释，协议预先固定 mean_margin 分桶 [0,.5,.8,.9,.95,.99,1]，variance 分桶 [0,.0001,.001,.01,.05,.2501]，除末桶含右端点外均左闭右开；逐桶在相同候选内比较，保留空桶。high_pos 在部分窄 margin/variance 桶仍有有利信号，例如 margin [.95,.99) AUROC 差 +0.010379，CI [+0.001653,+0.018986]；variance [0,.0001) 差 +0.002222，CI [+0.000645,+0.003947]。这些是预定义条件开发分析，不能替换主效应，也不能证明独立信息或因果机制。完整条件分数、风险和 CI 在 conditioned_metrics / conditional_paired_differences。

base_mu 是 K8 成员之一；同一组样本下理论上 var≥abs(mu−base_mu)^2/7（float16 量化前）。因此 Base-to-Mean 差与 variance 有结构性关联，q_A 是已有提示输出的确定函数。分桶没有联合精确匹配全部 margin、variance 和 Box，不能声称“改善已被完全解释”，也不能声称发现了独立的新证据。
