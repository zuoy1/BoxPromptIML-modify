# FECD 阶段 3R：研究路线与独立验证方案

日期：2026-10-29。状态：**方案设计完成；以下新实验均未运行**。阶段 3 的 NO-GO 保持有效。本文不构成启动训练、实现新损失、重跑 SAM 或进入原阶段 4 的指令。失败事实见 [复盘报告](stage3r_failure_analysis.md)。

建议优先选择 **路线 A 的最小教师诊断**，先弄清已有共识信号相对概率 margin 的价值及监督预算影响。路线 B 只在匹配参考条件下验证新的取证信息；原异常乘法不再作为可继续堆叠模块的基础。A 的工程确定性较高，但论文新颖性风险同样很高；目前两条路线均没有新的有效性结果。

## 1. 研究问题与已有工作的边界

| 原始文献 | 已有内容 | 本项目不能据此声称的新颖性 |
|---|---|---|
| [BoxPromptIML，AAAI 2026](https://arxiv.org/abs/2511.20359) | 粗框提示、冻结 SAM 教师、轻量学生蒸馏 | 用 SAM 蒸馏原学生网络本身 |

| [Noiseprint](https://arxiv.org/abs/1808.08396) | 相机模型痕迹、内容泄漏和取证局限 | 噪声残差或纹理抑制作为全新概念 |

这是有限范围的原文核对，不是完整优先权检索，也不证明某个完整组合具有首创性。候选贡献应是：**某种信息在控制 SAM 稳定性、几何条件与监督量后仍具有可重复增量价值，以及清晰的适用边界**。只有后续独立验证和更完整文献对照通过，才能考虑论文创新表述。

## 2. 路线 A：SAM Consensus-Aware Distillation

### 2.1 核心假设与可被否定的预测

**A-H1，条件排序信息：**相同 K8 预测和相同正负候选集合中，prompt 稳定性相对仅概率 margin 的收益主要集中在 Box 边缘/提示敏感区域；在已经稳定的内部区域，收益有限。必须用区域内相同 coverage 的比较验证，而非把简单背景重新分配进来。

**A-H2，剩余错误信息：**在已有 c_sam 条件下，K1/base 与 K8 均值差异是否还提供错误排序信息，尤其 high_pos FP？缓存可支持的一个最小固定候选为 `d=abs(mu−base_mu)`、`q_A=c_sam/(1+d)`，正负类同式，仅用于排序。无可调乘子，不先实现。它不是创新结论，也不是校准正确概率；只检验 base 响应相对汇总统计是否有剩余信息。

base 是 K8 内的一个 prompt，并非独立教师；d 与 variance 相关，var=0 时 d=0。必须同时对照 margin、variance、threshold uncertainty 和 c_sam，避免把重复信息误写为新来源。缓存没有完整逐 prompt 概率栈，不能据现有 mu/var/agreement 重建任意 prompt 协方差、独立投票或 leave-one-prompt-out 分析。当前不重新生成缓存。

**A-H3，监督预算：**正负类分别限制 coverage、对不确定像素弃权，是否比全图统一阈值更好地控制错误监督；其收益是否来自排序，而非只是减少监督量或增加背景占比？它可能改善有限覆盖的监督纯度，不能保证学生学得更好。

H1 的几何交互、H2 的剩余信息、H3 的预算分解构成可检验问题。即使成立，组件本身仍可能缺乏新颖性；若 H2 无增量，只能报告共识的适用范围或工程基线，不得重命名为 FECD 的取证创新。

### 2.2 选择、uncertain 与 Box 的角色

先固定 K8 `pred=mu>=0.5`。按预测正/负类独立排序，coverage 相对于各自候选集计算；全图统一阈值只作有覆盖率说明的对照。主要比较使用逐图 50% 正类 coverage，另报 10/25/75/90%；负类也用相同五档。记录正负数量、full-image coverage、所占监督质量及空正类图。

uncertain 的第一基线是忽略，不自动变为背景。未来如研究 soft target，仅使用既有 mu，先在同一 trusted 选集、同一相对正负监督量上比较 hard/soft target。若另给未选中的 uncertain 像素加入软监督，必须明确新增的选集、正负预算和权重质量，并加入同量随机 uncertain 监督对照；这同时改变监督内容与预算，不能将收益仅归因于软目标。不能同时改变分数、阈值、软目标和损失后把收益全归给 consensus。权重总和匹配也不等于有效样本完全相同，必须记录选集和目标差异。

Box 沿用冻结坐标与内部/边缘/环带定义。主排序比较在区域内固定 coverage，以隔离排序信息；区域预算调整是另一个实验。不得将 Box 内全标前景、Box 外全当绝对背景。弱 Box 约束的潜在作用应与筛选分开；本阶段不设计或实现新的 Box loss。

FN 的机制只限于减少错误负监督：若 q_A 能降低负类固定 coverage 的 FN 风险，可以更安全地弃权；不能据此说恢复了漏检。稳定 FN 在 d≈0、var≈0 时可能仍不可见，这是 A 的结构性上限。

### 2.3 教师诊断基线与未来学生基线

先比较以下固定排序基线，不训练学生：K1 margin `2*abs(base_mu−0.5)`、K8 margin `2*abs(mu−0.5)`、`1−clip(4*var,0,1)`、`1−4*agreement*(1−agreement)`、冻结 c_sam、唯一新候选 q_A。K1 的 margin 也在共同的 **K8 候选集合**上比较，避免换教师预测导致评价集合变化；另单独报告 K1/K8 分割混淆。

未来若教师关卡通过并另获授权，才采用下表。编号以 `3R-A/` 为命名空间，不改写历史 B0–B5 定义。

| 对照 | 唯一主要变化 | 识别的收益来源 |
|---|---|---|
| B0 | 同条件 K1 hard 全监督 | 新训练成员上的基准，旧全量 B0 不可替代 |
| B1 | 换 K8 hard，全监督 | 教师 ensemble 的标签变化 |
| B2-random | K8，按固定正负 coverage 随机选择，忽略其余 | 单纯减少监督量 |
| B2 | 同 B2-random 的正负数量，按 c_sam 排序 | 稳定性选择优于随机的贡献 |
| B3 | 同 B2 的选择预算，仅换 q_A | 新排序是否有剩余贡献 |
| B4 | 同 B3，仅改变预注册的区域预算 | 几何分配作用，不能归给像素排序 |
| B5a | 同 B3 trusted 选集与预算，仅比较 hard/soft target | 目标表示的作用 |
| B5b | trusted 保持 B3，给 uncertain 明确额外监督预算，并设同量随机对照 | 新增不确定监督的作用，不能视为纯目标消融 |

这是受控设计清单，不是承诺一次训练所有分支。先 B0–B3，只有对应假设成立才讨论 B4/B5。每个分支均保留原学生网络、相同初始化、图像、增强、更新步数、优化器与 seed；未来至少 3 个共同 seed。离线缓存只允许已验证的同步几何增强，不能让强颜色/JPEG/拷贝增强与旧教师标签、取证图不一致。完整旧 B0 checkpoint 不能作为初始化，因为它训练过未来确认成员。

## 3. 路线 B：Forensic-Aware Reliability 的重新设计

共同问题是：**在相似 SAM 分数、位置、亮度、纹理、尺度和压缩条件下，取证证据还是否解释错误？**先检验这个条件信息，再讨论融合。下列候选互为研究选项，不全部并行实现，不叠加 Confidence Head 或复杂网络。

### B-R：参考区域条件下的残差分布一致性（优先的 B 子路线）

1. **修补缺陷：**原版把局部异常当作正类支持，没有明确参考。改为比较候选 patch 与同图、相近内容条件的参考 patch 的残差尺度/分布差。
2. **高一致性错误机制假设：**某些稳定 FP 可能与可信背景参考具有一致成像统计，而真实异源插入存在不一致；某些稳定 FN 可能与周围背景统计不同。这里的“背景参考”由固定 SAM/Box 规则选择，不是 GT 验证真背景，参考也可能出错。
3. **相对 prompt 共识：**使用成像统计关系而非模型对框扰动的稳定性；即使 SAM 输出不变，残差比较仍可能变化。
4. **新增输入与成本：**使用允许的训练原图、缓存 Box 和 SAM；未来提取固定工作尺度的 64×64 patch 残差（32 仅作预注册尺度敏感性），以亮度和梯度匹配参考，统计 MAD/分位数差或一个固定两样本距离。主统计量只选一个并在开发后冻结。CPU patch 计算，无需 SAM 推理或学生训练。
5. **最低成本证伪：**先在 new_dev 每域 hash 前至多 16 图（最多 62 图）检验参考可用率、方向、自然纹理负控和同条件 FP/TP 区分；再在全部开发组验证。若相似度不能稳定判定哪一侧可信、匹配后信息消失，或参考不足一半候选图，不打开确认 GT，停止该机制。
6. **泛化风险：**copy-move/同设备拼接可能与原图统计一致；大篡改区域污染参考；低纹理区噪声弱；统一缩放/压缩会抹平差异。不能把“不一致侧”在确认 GT 上择优翻转为篡改侧。

### B-T：显式内容条件化与纹理干扰抑制

1. **修补缺陷：**原除以梯度的固定补偿没有排除残差中的内容泄漏。
2. **高一致性错误机制假设：**在给定梯度、亮度和尺度的自然基线后，残差超出该内容条件预期的部分才可能提供 FP/TP 差异；高纹理稳定 FP 的高原始异常可被解释为内容，而非篡改证据。
3. **相对共识：**条件变量来自图像与处理历史，不依赖 prompt 稳定性。没有剩余信息时应接受无增量。
4. **新增输入与成本：**先只用新 student_train 做 GT-free 的少量条件分箱稳健统计，或固定的低维稳健回归；在 new_dev 检查条件残差。无需训练视觉网络。若需要真实自然区域基线，必须另有获准使用且来源独立的 authentic 数据，不能把 SAM 背景或正式测试 GT 冒充真自然参考。
5. **最低成本证伪：**与原 residual、纯梯度和 SAM-only 作同组、同 coverage 比较；在同纹理区间置换 evidence 作为负控。如果“改善”完全由梯度/亮度解释、仅一个域有效，或条件化同时消除了全部候选错误信息，就停止。置换只作开发分析，不拿显著性挑最优分箱。
6. **泛化风险：**学习到数据集/设备/分辨率特征；分箱支持稀疏；新域纹理分布超出训练范围。域 ID 不作为主要可靠性输入，未知条件应弃权并报告 coverage。

### B-C：条件化 JPEG/频域兼容性

1. **修补缺陷：**一次 Q90 残差缺少原管线、块相位和尺度条件；通用 FFT 混合内容边缘与处理痕迹。
2. **高一致性错误机制假设：**某些稳定错误区域与参考区域的块/频谱规律一致，而异源插入不兼容；或稳定漏检区域保留不一致。该假设仅对存在可观测处理差异的样本成立。
3. **相对共识：**检验压缩/频率生成机制，不是再量一次 SAM variance。
4. **新增输入与成本：**先核对已有原格式、JPEG 量化表与 native 尺寸元数据；未来只在预先定义的 JPEG 适用域研究 native 8×8 相位/量化条件，或固定 native 尺度下相对匹配参考的频谱统计。未知历史、非 JPEG 的压缩分支为不适用，不补零。小批 CPU 计算；原图解码和假设核验成本高于 A。
5. **最低成本证伪：**先 GT-free 格式/条件覆盖率，再用开发中的匹配自然参考和固定质量/相位扰动负控。若响应主要随全图重编码或自然边缘变化、条件匹配后无 FP 信息，停止。Q75/95 只作注册敏感性，不能在确认集挑 Q。
6. **泛化风险：**多次压缩、未知编码器、TIFF 内的历史压缩、统一后处理和重采样。JPEG 子集收益不得外推到全部数据集；必须报告适用率，并在相同适用候选集合比较，不能靠排除难域得利。

B 的所有候选首先输出机制统计，不直接替换为新的篡改概率或再次盲乘 c_sam。开发阶段必须确定可靠性方向、参考失败处理及唯一主统计；确认前锁定。一个证据若只能揭示“两区域不同”却不能决定当前教师哪边错，只能支持弃权假设，不能宣称纠错。

FN 分支必须单独注册并验证：候选证据能否在预测负类固定 coverage 下识别错误负监督？在无证据前保留 c_neg 基线，不将异常负类自动翻正。正类成功不构成 FN 成功。

## 4. 新开发/确认协议：先隔离，再做新方法

### 4.2 独立性的真实边界

3,020 张是 donor-token **连通分量**，不能称同一原图的 3,020 个版本。它占草案训练图像 85.55%、训练 CASIA 92.13%；新确认没有该分量，因此只对较小分量代表的分布作内部判断。不能为比例好看拆开大组。未来应同时报告 image-weighted 与 group-equal 敏感性，并做不把大分量当多个独立来源的训练组成说明。

CASIA/Columbia 仍是代理来源，缺乏完整真实 provenance。NIST 新确认只有 9 组、Columbia 6 组、Coverage 14 图/14 组。尚未看新 GT，不能知道混合 TP/FP 的有效组数或预报 power；不能保证充分四域确认。若论文需要有力跨域结论，需要另获来源可靠、未进开发、与所有已有训练/开发/确认去重的新数据，不能挪用正式 IND/OOD 测试作调参集。

已知 NIST `world/NC2016_0359.jpg` 的两个历史训练成员在旧 teacher_diag，不进入本次 fit 衍生草案；历史全训练与正式测试同源风险仍存在，不据此宣称整个基准已无泄漏。

新确认只能称“**新研究中尚未打开像素 GT 的内部确认候选**”。这些图此前参与 GT-free 归一化和分布分析，部分图被无 GT 可视化；其 GT 还曾用于离线 Box 导出，历史 B0 训练也不能视为隔离。因此不是完全未观察的 pristine 数据或无标注数据。新实验不得使用历史全量 B0 作训练初始化或从其表现选方案。

### 4.3 新统计、GT 防线与一次性确认

- 若需要归一化、参考库、条件分箱或回归，只在新 student_train 拟合，另存版本；不复用覆盖未来确认图的旧统计作为主要独立协议，不覆盖旧 stats。旧确定性原始 evidence 与 SAM 可按身份只读复用；B 的新描述子将来另存版本，当前不生成。
- new_dev 允许在专用诊断入口读取 GT，用于有记录的有限开发；不向 Dataset、分数模块、reference fitting 或未来学生入口传 GT。开发使用标签不等于学生训练获得标签；论文须披露使用了诊断标注，不能声称方法选择完全 label-free。
- new_confirm 在主公式、方向、适用域、覆盖率、统计和停止条件冻结后只打开一次。未来须新增版本化、按角色 allowlist 的专用评估入口；不放宽旧 audit_pseudo 的 teacher_diag 限制，也不把新 mask 写入学生缓存。
- 确认失败不能改公式后再把同一集合称独立确认。若两条路线都要比较，必须在任何确认 GT 前登记两者和多重比较规则；不能 A 失败后把 B 当作同一确认集上的新独立发现。更节省确认资源的默认方案是用户先选一条路线、一个主候选。
- 新确认若已用于教师路线终裁，也不再是未来反复学生调参的未见集。学生实验须另立预注册、固定模型选择规则；最终泛化仍需未用于选择的数据。正式 IND/OOD 测试继续锁定，只有未来全部设计冻结并另获授权后才作最终评估。

低成本替代是仅用旧 teacher_diag 做开发，把上述 530 new_dev 归还训练，形成 4,060 训练/530 新确认；这保留更多训练图，但开发完全继承旧自适应分析的偏差。它不增加小域确认组数，也不能试完两种分配后选成绩好的一种。默认推荐三角色方案；用户可在新 GT 访问前选择替代。

## 5. 两条路线共用的最小可证伪协议

### 5.1 先冻结评价对象，避免预算和方向混淆

沿用 224×224、GT NEAREST 后 >127、K8 pred>=0.5、高一致性 c_sam>=0.90 且 var<=0.01，以及原 Box 内部/边缘/环带定义。分数高表示可靠，error score=1−score；N/A 和并列分数按原精确逐图实现处理。比较方法必须共享候选集合；B 的不可适用候选需另报适用率和在共同适用集合上的结果。

主要端点：候选−c_sam 的 **high_pos 精确 per-image AUROC 差**。共同必要端点：**pos 精确 per-image risk@50% 差**。分别报告 AP 与 error prevalence、AURC、五档 coverage risk/precision、trusted positive/negative conditional/full coverage、FP/FN 数、Box/面积/域分项。不用固定阈值 precision 代替同 coverage 比较。

2,000 次 whole-source-group 配对 bootstrap，seed=20261029，主估计量 image-weighted macro；增加 group-equal 与四域等权的描述性敏感性，不用它们替换不利的主结果。micro 只描述，明确原直方图近似限制；若需精确 pooled 值应另作只读计算，不能称旧值精确。禁止像素独立显著性推断。

以下是**新协议建议门槛，未从新 GT 拟合，也未验证其统计功效**：high_pos AUROC 点改善至少 0.02 且 CI 下界>0；pos risk@50% 点下降至少 0.002（0.2 个百分点）且 CI 上界<0。数值作为最低实用效应约定，须在新 GT 开放前定案。负类 risk@50% 非劣界限为 +0.001（0.1 个百分点），其差值 CI 上界不得超过该值；若宣称 FN 改善，必须另满足负类下降 CI 上界<0，并披露 high_neg 的结果。

正式 GO 是 high_pos AUROC 优效、pos risk50 优效、negative risk50 非劣的共同声明，不能挑其中之一；每条路线最多一个确认候选。默认只确认用户所选的一条路线。若预注册同时确认 A、B，采用更保守的同步界：对两路线共 6 个定向约束作 Bonferroni，单侧 alpha=0.05/6；source-group bootstrap 增至 10,000 次，分别使用相应 0.008333/0.991667 分位界作正式判定，另外输出未调整的 95% CI 作为描述。新推断实现和全部界限必须在打开确认 GT 前验证并冻结，不能把原脚本的 95% CI 冒充已校正结果。少组时 bootstrap 仍只是近似，不能靠调整置信水平解决数据不足。有限开发分支全部记录，不以成功案例挑方法。

每域同时报告所有结果；域级确认建议至少 20 个有效来源组、20 张有效配对图及 50 个候选错误，不满足标为证据不足，不以像素数量补足。达到门槛的域必须同方向；小域不得在开标签后从研究范围删除。现有草案的 NIST/Columbia/Coverage 不足以保证该门槛，这是数据缺口，不能降低门槛隐藏。

### 5.2 A 的最小执行顺序与停止条件（未执行）

1. **元数据关卡：**选定并冻结派生划分，排除全量旧 B0 初始化，验证只读缓存身份及 GT 隔离。
2. **开发诊断：**在 new_dev 比较第 2.3 节六种 score，采用共同 K8 候选；同时比较 Box 内部/边缘的区域内固定 coverage，以及相同区域预算的结果。先查 H1/H2，再做监督分配。随机同量选择只作覆盖量负控。
3. **开发淘汰：**若 q_A 相对 c_sam 没有一致方向的 high_pos AUROC 和 pos risk50 改善，或完全由 margin/区域预算解释，停止“新增排序信息”主张，不打开确认标签。不继续遍历任意乘子寻找最好结果。若仅边缘条件有用，须重新限定假设并在未开确认前登记；不能确认后收窄范围。
4. **一次确认：**只有一个开发主候选和固定分析进入 new_confirm。候选在 high_pos 无足够有效图/组时标不确定，不补零；不能仅依赖全正类收益宣称识别稳定错误。
5. **训练必要性判断：**只有确认有可靠监督排序增量，且负类无实质恶化，才有理由另行请求学生对照；教师筛选改善仍不是学生收益证明。若 c_sam 已优于所有候选，可保留其为工程基线，但不以新论文创新为由自动训练。

计算预算：复用现有 cache，读取至多 530 图的开发数据，先跑一次开发、一次冻结确认；无需 SAM/GPU 推理。与阶段 3 的 1,147 图运行相比数据量较小，但这里没有测时，不承诺分钟数或显存。

### 5.3 B 的最小执行顺序与停止条件（未执行）

1. **选一种机制：**默认仅 B-R；先明确参考选择、主 patch 尺度、单一距离统计、可靠性方向的开发规则及参考失败处理，不同时尝试所有描述子组合。
2. **可用性筛查：**先只用 student_train 图拟合 GT-free 统计；开发按每域 sample_key 字典序前至多 16 图检查匹配参考、自然纹理与格式负控。合成改变只检查特征机制，不能当作真实篡改有效性。
3. **条件信息检验：**在开发的相同 c_sam 区间、预测类别和 Box 区域内，按亮度/梯度/尺度/压缩条件匹配，检查 FP/TP 区分。仅有全局 r 相关或域均值差不算通过。匹配需报告支持不足及被排除量。
4. **增量排序检验：**机制检查通过后，才在开发确定一个简单、固定的证据使用规则；比较 SAM-only、evidence-only、SAM+新证据和只用纹理/格式的负控，在相同 coverage 上评价。记录全部尝试；不训练 Confidence Head，不在确认集决定正负方向。
5. **提前停止：**参考不可用超过半数候选图、方向随域翻转、匹配后信息消失、主要反映自然纹理/编码条件、high_pos 无增量、或负类规则未经验证，都不进入相应确认/训练阶段。只在预定义 JPEG 子域有效可形成窄域假说，不能变成通用 FECD GO。
6. **独立确认：**主方法、统计及适用率下限锁定后，按共用协议一次终裁。无需重建 SAM 缓存；任何未来新增 evidence 独立存储，原 v1 原样保留。

## 6. GO / CONDITIONAL GO / NO-GO 的含义

这里的判断都是**将来要执行的规则，本次未产生 A 或 B 的 GO 结果**。

- **GO：**主 AUROC 与必要的 coverage-matched risk 同时达到第 5.1 节效应/CI 门槛，负类无实质恶化，预注册适用域有足够来源组且方向一致，无严重未解决的纹理/格式捷径。它只支持另行讨论学生实验，不能证明学生或论文已经成功。
- **CONDITIONAL GO：**两个主方向有利，但样本/组数、域一致性或机制负控不足。明确补充来源、参考有效性或窄域验证任务；不自动进入学生训练，不以局部成功抵消整体不确定性。当前内部小域规模使严格四域 GO 很难仅靠这份草案获得。
- **NO-GO：**主要方向不利、同 coverage 风险更差、只因 coverage 缩小而 precision 提高、证据仅有域/纹理关联、或确认失败。停止该候选；不得用 Confidence Head、Consistency 或更复杂网络覆盖失败。

缺少足够混合错误或来源组时属于证据不足，不能宣称已证明无效；但同样不能据此启动完整训练。确认一旦消耗，任何修订都需要新的确认资源和版本。

## 7. 贡献潜力、成本与推荐选择

| 维度 | 路线 A | 路线 B |
|---|---|---|
| 首要问题 | 已有共识信号如何分配可信监督，何处失效 | 成像统计是否含 SAM 稳定性之外的条件错误信息 |
| 可复用资产 | K1/K8、c_sam、Box、全部诊断代码 | 同左，加原始图像/格式与取证缓存 |
| 最低新增成本 | 缓存上的少量 score 与配对诊断；当前不训练 | 参考匹配/新统计/机制负控，可能需要新 authentic 或来源明确的数据 |
| 新颖性风险 | 高：常见 uncertainty、pseudo-label selection 和类平衡组件 | 仍高：来源一致性已有先例，但条件增量问题更接近原 FECD 目标 |
| 主要失败上限 | 相关 prompt 的共同稳定错误、稳定 FN 仍不可见 | 自然内容与采集管线混淆、同源 copy-move、参考污染与不适用域 |
| 能形成的候选贡献 | 严格控制预算后的条件收益与失效边界；需学生与外部确认才谈方法论文 | 可解释且跨来源验证的独立条件信息；机制成立前不能称有效取证方法 |
| 是否现在进入训练 | 否 | 否 |

**推荐顺序：先选择 A 的最小教师诊断，再决定是否值得学生验证。** 理由是它直接检验现有资产中剩余的有效信息，成本最低，也能先排除“收益只是少监督或多背景”的混淆。它不是把已失败的 FECD 换个名字；若没有超越强 SAM-only 基线的条件增量，应接受它仅有工程/分析价值。

如果研究目标必须保留独立取证创新，应选择 B-R，先证明参考条件下的错误信息存在，而不是继续增强旧四特征乘法。其论文潜力更依赖新增机制和独立数据，成本与失败风险都更高。目前不能保证现有内部资料支持有力跨域确认。
