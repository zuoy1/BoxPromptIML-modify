# FECD 阶段 3R-B0-M：负控统计解释与机制停止结论复核

日期：2026-10-29。本报告是既有结果的事后只读解释审计，不是新机制开发或新的预注册检验。**最终行动保持 STOP**。原阶段报告、protocol、停止线、公式、缓存和结果均不修改。

## 1. 核心判断：STOP 正确，不等于分布相同

冻结条件为：至少 10 张可配对图，目标 D≤同图控制 q95 的逐图比例宏平均≥50% 时 STOP。原 60 张配对图、75.6389% 的计算与条件完全一致；本轮复核主尺度及既有 32 尺度均重现。不得因本轮看到其他描述量而改线、改判或恢复开发。

同时，**75.64% 在 q95 内不能证明目标/控制分布相同**。以完全相同的 60 图比较，控制 D 超过自身 q95 的逐图宏比例为 8.8944%，目标为 24.3611%，逐图差平均为 +15.4666 个百分点；组等权差为 +12.0079 个百分点。已有尾部描述显示差异，不支持把 STOP 误译为“未观察到任何分布差异”。但差异也不证明独立篡改证据、TP/FP 可分、定位有效或可改善教师监督。

工程事实、决策规则、分布描述和错误识别能力是四个不同层次。原 summary 的原因字符串 candidate_difference_not_separated_from_ordinary_reference_proxy_variation 应仅按“未通过这个预设机制门槛”理解；若将它扩张成“分布同一/统计差异不存在/所有取证机制无效”，属于解释越界。原报告已披露无 GT 限制，本报告进一步限定其语义，保留所有历史文本原样。

## 3. q95 到底如何形成

### 3.1 锚点、匹配条件与参考身份

每图最多 16 个控制锚点，来自满足原 reference_eligible 条件的完整参考池、按既定索引等距抽样；控制仍需找到至少 3 个互不重叠的内容匹配参考才有 D。60 图各实际审计 16 个控制，另 2 图无合格控制锚点，共 960 个审计控制、781 个成功控制。有效控制数不是总参考池大小，也不是每个 D 使用的 3–5 个参考数。

目标锚点来自原 pos / box_inside / box_edge 的并集，按原分类抽样并去重。原 pos 表示 SAM 正类比例≥75%，不是 patch 100% 正类；所谓“纯 SAM 正类”在本报告指该原 pos 类，不另设更纯阈值。目标包括 Box 类中的 SAM 负类；仅具 neg 类别而不属于 Box 目标者不纳入主目标。

目标和控制都调用同一个 match_references 与 compare_regions：相同参考资格、空间排斥、内容门槛、排序、3–5 参考规则和固定 D。**相同匹配函数并不等于锚点选择机制相同。** 控制锚点本身已保证 Box 外和高稳定负类；目标锚点由 SAM/Box 规则选出，没有同等资格约束，且两者抽样格局和最终可用率不同。

所有候选及控制记录中，自己的 patch id 进入自身参考集计数为 0。代码首先排除与候选空间相交的参考，因此相同锚点一定排除；同时检查所选参考彼此不相交。不同控制锚点可成为对方参考：主尺度记录到 590 次“某个有效控制的参考恰好是另一个有效控制锚点”身份实例，不是 590 个独立区域。这意味着不是自参考，但存在交叉依赖。

### 3.2 分位数、有限样本与并列值

旧实现 np.quantile(cv,.95) 的默认方法为 linear，本轮显式 method='linear' 复现。排序值 c_(1)...c_(n)，零基 h=(n−1)×0.95，取相邻次序值作线性插值。原始 residual 分位数与描述性 summary 分位数也使用 NumPy 默认 linear；参考中位数按 np.median，偶数时平均中间两值。

超过定义为严格 D>q95；原 STOP 的“位于以内”为 D≤q95，等于阈值的 ties 归入以内。没有 jitter、随机拆 ties 或改用其他 quantile 方法。若无有效控制则 q95=N/A；无有效目标则目标比较 N/A，不填零。

若顶部并列，插值 q95 可等于最大值，严格超过数可为零；全相同值也为零。这是当前代码应有语义，本批两尺度均未出现恰好等于 q95 的有效控制。不能将理论名义 5% 当成现有 self-exceed 结果，也不能把 self-exceed 当独立新控制的假阳性率。

q95 从同一小批、空间相关且复用参考的控制 D 估计，再回到自身评估，是 in-sample 描述。有限样本尾部不稳、控制间依赖、条件内容差异、无真实背景标签共同限制其解释；未作留出校准、外部自然参考校准或真正的交换性验证，本轮不追加这些实验。

## 7. 对五个问题的限定回答

1. **75.64% 在 q95 内能证明分布相同吗？** 不能。这是一个经验阈值下的比例，不是分布等同性/等效性检验；它对应24.36%目标超率，控制实际自超率8.89%，既有数据存在尾部描述差异。即使单点比例相同也不能证明整分布相同。

2. **24.36% 超过 q95 足以证明独立篡改证据吗？** 不足。它是已匹配目标对 SAM/Box 选择的控制代理的事后差异，可能涉及内容、来源、压缩、空间支持、锚点选择、控制 in-sample q95 及共享参考。没有真实 TP/FP 标签、可靠自然锚点或独立控制，不能归因为篡改，不能给正确性方向，更不能证明在 c_sam 之外提供错误排序增量。

3. **两种选择机制足够可比吗？** 只达到“同图、相同匹配条件和统计定义”的操作可比性，未达到交换性。控制已经是 Box 外稳定负类，目标不需满足同等条件，两者适用率与空间/内容支持不同；共有参考又增加依赖。当前结果不能区分这些解释的贡献。

4. **正类50.41%可匹配意味着什么？** 仅一半被审计正类有 D，不匹配者不是正常或错误；小 Box 缺该尺度纯正类支持，大 Box 易无参考，跨域比例差异明显。未来整体方法需处理弃权和选择偏差，不能拿已匹配子集的尾部差替代全候选有效性。

5. **当前无GT可得什么结论？** 可确认工程可计算且无自参考，原停止线正确触发，目标与控制存在异质的尾部描述差异，参考支持不足且强依赖SAM/Box，尚未建立可信的错误识别解释。不能确认真实背景、分布同一、因果成像差异、TP/FP能力或学生收益。

A. **已验证工程事实**：固定输入/坐标/特征的历史实现可运行，统计和 STOP 可复现；本轮旧 JSON 中自参考为0，但共享参考、跨锚点重叠和缺失支持真实存在。既有工程PASS保持。
